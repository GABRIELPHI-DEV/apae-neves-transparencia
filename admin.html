Editar o portal

Altere os campos, veja a prévia e publique. Os textos em “Leitura fácil” aparecem para quem ativa essa opção no site.

Publicar no site

Envia o dados.json (e as fotos novas) direto para o GitHub. O site se atualiza sozinho em cerca de um minuto. Você precisa de um token do GitHub com permissão de escrita em Contents só neste repositório. O token fica apenas nesta aba e some quando você a fecha.

Sem token? Use “Baixar dados.json” e, no GitHub, abra o repositório, clique em Add file, Upload files e envie o arquivo para substituir o antigo.
